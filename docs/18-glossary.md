# 18 · Glossary

Plain-English meanings of the words used across the documents.

## Product and business

| Term | Meaning |
|---|---|
| **PRD** | Product Requirements Document: says *what* the product must do |
| **TRD** | Technical Requirements Document: says *how well* and *with what* it must be built |
| **Persona** | A realistic example of a type of user, used to design for real needs |
| **User journey** | The steps a person takes to reach a goal |
| **Lead** | A person who showed interest in a listing (unlocked contact or sent an enquiry) |
| **Listing** | One property advertised on the site |
| **Verified badge** | Shows a listing has documents and all are verified by our team |
| **MVP** | Minimum Viable Product: the smallest version that is useful |
| **KPI** | Key Performance Indicator: a number you track to know if you are winning |
| **UAT** | User Acceptance Testing: real users try the product before launch |
| **SLA** | Service Level Agreement: a promised response time (e.g., review within 3 days) |
| **RACI** | Who is Responsible, Accountable, Consulted, Informed |

## Land and legal (India)

| Term | Meaning |
|---|---|
| **MIDC / GIDC / RIICO / SIPCOT / TSIIC** | State industrial development corporations (Maharashtra / Gujarat / Rajasthan / Tamil Nadu / Telangana) that run industrial estates |
| **7/12 extract (Satbara)** | Land record showing owner and land details in Maharashtra; other states have equivalents (RTC, Patta, Khata) |
| **NOC** | No-Objection Certificate: permission/consent from an authority |
| **NA (non-agricultural) order** | Permission converting farm land to non-farm use |
| **Encumbrance certificate** | Shows registered loans, mortgages or charges on a property |
| **Mutation entry** | Record change when ownership changes hands |
| **FAR / FSI** | Floor Area Ratio / Floor Space Index: how much can be built relative to the plot size |
| **Freehold / leasehold** | Full ownership vs. right to use for a long term under conditions |
| **RERA** | Real Estate (Regulation and Development) Act; state authorities register projects and agents |
| **DPDP Act** | India's Digital Personal Data Protection Act, 2023 |
| **DGPS survey** | High-precision GPS land survey (we only mention it where it is truly done) |
| **Crore / Lakh** | 1 crore = 10,000,000; 1 lakh = 100,000 |
| **Acre** | 43,560 sq ft ≈ 4,047 sq m |

## Technology (simple)

| Term | Meaning |
|---|---|
| **Frontend / backend** | What you see in the browser / what runs on the server |
| **Server rendering** | The server builds the page's HTML before sending it, so Google and slow phones get content quickly |
| **Framework (Next.js, React)** | Ready-made building blocks for websites |
| **TypeScript** | JavaScript with checks that catch mistakes early |
| **Database (PostgreSQL)** | Organised storage for all the site's information |
| **Supabase** | Service that provides the database, login and file storage |
| **RLS (Row Level Security)** | Rules inside the database that decide which rows each person may read or change |
| **Trigger** | An automatic rule in the database that runs when data changes (used to stop self-approval) |
| **Migration** | A versioned SQL file that changes the database structure |
| **Server action** | A function on the server that a button in the page can call safely |
| **API key** | A password-like code that lets software use a service |
| **Service role key** | A powerful key that bypasses database rules; must stay on the server |
| **Publishable key** | A key that is safe to show in the browser because the database rules protect data |
| **Environment variable** | A setting (like a key) stored outside the code |
| **Cache** | A saved copy so pages load faster; refreshed when data changes |
| **CSS variable** | A named style value (like a colour) that can be changed in one place |
| **Signed URL** | A temporary web link to a private file that expires |
| **Rate limit** | A cap on how often someone may do something |
| **CAPTCHA** | A test that tells humans from bots |
| **OTP** | One-time password sent by SMS |
| **OAuth** | The standard behind "Sign in with Google" |
| **Proxy (middleware)** | Code that runs before a page loads (used for redirects) |
| **Fallback** | A safe plan B when something fails |
| **LLM / Grok** | A large language model; Grok is xAI's |
| **Prompt** | The instruction given to an AI |
| **Hydration** | The step where a server-built page becomes interactive in the browser |
| **CI/CD** | Automatic testing and deployment on every change |
| **Staging** | A copy of the site for rehearsal before production |

## SEO

| Term | Meaning |
|---|---|
| **SEO** | Search Engine Optimisation: getting found on Google |
| **AEO / GEO** | Being cited by AI answer engines |
| **Meta title / description** | The headline and snippet shown in search results |
| **Canonical URL** | The "official" address of a page, to avoid duplicates |
| **Structured data / JSON-LD** | Hidden labels that tell search engines what a page is (listing, FAQ, article) |
| **Sitemap** | A list of all pages for search engines |
| **robots.txt** | Rules telling crawlers where not to go |
| **noindex** | Ask search engines not to list a page |
| **301 / 302 redirect** | Permanent / temporary forwarding from one URL to another |
| **Lighthouse** | Google tool that scores speed, SEO and accessibility |
| **Core Web Vitals** | Google's speed and stability measures |

## Process

| Term | Meaning |
|---|---|
| **Waterfall** | Plan everything, then build in fixed stages |
| **Agile** | Build in small steps with frequent feedback |
| **Scrum** | An Agile method with fixed sprints and meetings |
| **Kanban** | An Agile method using a work-flow board |
| **Sprint** | A fixed work period (usually 1 to 4 weeks) |
| **Backlog** | The prioritised to-do list |
| **Definition of Done** | The checklist that must pass before work counts as finished |
| **Pull request** | A proposed code change that others review |
| **ADR / decision log** | A record of why a decision was made |
